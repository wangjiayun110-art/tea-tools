# Tea Tools

Small free web tools from [Tea & Stillness](https://calmsteep.com) — each one is a single self-contained page (or folder) you can open in a browser. No build step, no server needed.

## Tools

| Tool | Folder | Live page |
| --- | --- | --- |
| Tea-Leaf Ratio Calculator — how much leaf and water for 6 teas, cup or gongfu style, both directions | `tea-leaf-ratio-calculator/` | https://calmsteep.com/tea-leaf-ratio-calculator.html |
| Tea Card Gacha — free draw, no sign-up: 24 tea cards with origin and brewing parameters, collection album saved in the browser | `tea-card-gacha/` | https://cn.calmsteep.com/tea-card-gacha.html |
| Image Format Converter — WebP / HEIC / PNG / JPG / AVIF / GIF / BMP to JPG, PNG or WebP, converted in the browser, nothing uploaded | `image-converter/` | https://calmsteep.com/image-converter.html |
| WebP to JPG | `image-converter/webp-to-jpg.html` | https://calmsteep.com/webp-to-jpg.html |
| HEIC to JPG | `image-converter/heic-to-jpg.html` | https://calmsteep.com/heic-to-jpg.html |
| Singapore Income Tax Calculator (YA2026) | `singapore-tax-calculator/` | https://cn.calmsteep.com/xinjiapo-geshui-jisuanqi.html |
| Malaysia Income Tax Calculator (YA2025) | `malaysia-tax-calculator/` | https://cn.calmsteep.com/malaixiya-geshui-jisuanqi.html |

The image converter loads `heic2any` and `JSZip` from its own `js/` folder — no CDN needed. The tax calculators are Chinese-language pages for overseas Chinese readers in Singapore and Malaysia.

The tea brewing timer lives in its own repo: [tea-brewing-timer](https://github.com/wangjiayun110-art/tea-brewing-timer).
